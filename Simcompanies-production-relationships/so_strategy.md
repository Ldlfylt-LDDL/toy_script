# Sales Office 收货策略分析

## 基本机制

- SO 合约随机刷新产品，**每张合约固定扣除 wages（约 33,000）**，无论是否履约
- 合约收入公式：`revenue = base_price × (1 + bonus% × quality)`
- `bonus%` 每张合约不同，历史分布近似**均匀分布 1.0%–3.0%**，均值 2.0%（来自 SalesOffice_archive.xlsx，398 条记录）
- 产品质量范围 Q0–Q12

## 核心决策原则

### 履约 vs 放弃
wages 是沉没成本，每张合约的决策只看货款：

```
合约每单位收入 > 收货价  →  履约
合约每单位收入 < 收货价  →  放弃（避免在 wages 之外再亏货款）
```

### 最优收货质量
利润关于质量是线性的：

```
利润(Q) = 常数 + Q × (base × bonus% − 市场步长)
```

存在临界值 `bonus* = 市场步长 / base`：
- 合约 bonus% > bonus*：Q 越高越赚
- 合约 bonus% < bonus*：Q 越低越赚

由于 bonus% 均匀分布 1%–3%，**除 SEP 外所有产品 Q12 期望利润最高**（单调递增）。

## JUM 特殊说明

聊天室 JUM 收价（Q3 约 244.5k）高于合约基础价均值（Excel 约 221.8k），
即使考虑"必须做"约束，按市场价外购做 JUM **所有质量均净亏**。

但：**不做 = 亏全部 wages；做了 = 亏 wages + 少量货款差**。

结论：仍应做 JUM，收 Q12（保本基础价要求最低，约 237.8k @ 2% bonus）。

## 混合质量策略评估

模拟结论：备 Q0+Q12 混合（按 bonus% 分配）vs 单备最优质量，每单位额外收益：
- SEP：+450，SAT：+571，LUX：+866，SOR：+920，JUM：+3,640，BFR：+4,613

BFR/JUM 混合收益较大，其他产品提升有限，维护两档库存的复杂度通常不值得。

## 收货价数据来源与更新方式

价格基于聊天室报价加权均值（`data/crude_data`），Q10–Q12 按市场步长外推。

更新命令：
```bash
node scripts/analyze_crude.js          # 重新分析 crude_data
node scripts/analyze_crude.js path/to/new_crude_data   # 指定文件
```

**建议每周更新一次**，或市场价格出现明显波动时重新抓取。
