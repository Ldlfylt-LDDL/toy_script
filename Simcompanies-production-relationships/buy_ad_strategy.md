# 收购广告定价策略

> 记录日期：2026-04-06  
> 适用场景：SimCompanies 零售商，面向无交易所的航天/高级产品，通过 OTC 收购货物

---

## 一、理论基础：买方最高出价上限

给定零售订单参数：
- `P0`：Q0 产品的基础售价（每单位）
- `b`：质量奖励百分比（小数，如 0.02 代表 2%）
- `qty`：数量
- `W`：工资成本（固定，不随质量变化）
- `π*`：目标利润（可为负，见第四节）

**最高收购价公式：**
```
p_max(Q) = P0 × (1 + b × Q) − (W + π*) / qty
```

**理论步长：**
```
Δp = P0 × b   （每质量级之间的无差异步长）
```

使用此步长时，交付任何质量的利润完全相同——高Q不多赚也不少赚。这是定价的**中性基准线**。

---

## 二、供给结构分析：三段划分

卖方的最低接受价（保留价）与买方上限的交叉结构：

```
价格
  ↑    p_max(Q) ─────────────────/  ← 线性上升（斜率 = P0×b）
  |                          /
  |         ┌───────────────       ← 高Q：顶端玩家要溢价，超出你上限
  |         │  ← 甜区（差价最大）
  |  ───────┘                      ← 低Q：小生产商成本高，底价反而高
  +──────────────────────────→ Q
        1   3   5   7   9   12
```

| 区段 | 卖家特征 | 供给价 vs 上限 | 策略 |
|------|---------|--------------|------|
| 低Q（≤ 门槛A） | 小生产商，成本高 | 底价 ≥ p_max，难盈利 | 不列或保本价，不期待成交 |
| 中Q（甜区） | 主力供给，竞争充分 | 差价最大 | 重点收购区间 |
| 高Q（≥ 门槛B） | 顶端玩家，收溢价 | 要价 > 增量收益 | 略高步长吸引，但仍需折扣 |

---

## 三、广告发布价：在上限基础上打折

直接发布 p_max 会暴露估价上限，导致卖家向上锚定。

**广告价 = p_max(Q) × discount(Q)**

| 区段 | 折扣系数建议 | 说明 |
|------|------------|------|
| 低Q段 | 0.80 或不列 | 进不来也无所谓 |
| 中Q甜区 | 0.85–0.90 | 留谈判空间，主力收购 |
| 高Q段 | 0.88–0.92 | 步长可略宽松（增量收益支撑） |

- 卖家私信询价时，可以从广告价往上加，上限是 p_max
- 折扣系数随合约历史数据积累后逐步校准

---

## 四、跨产品利润差异：π* 不应是全局常量

**核心认知：不同产品受市场结构限制，现实预期利润本就不同。**

- 某些产品市场供给充足、竞争激烈 → 现实利润率低甚至微亏
- 某些产品稀缺、需求稳定 → 利润率高
- 受限于市场，即使理论上可以设高 π*，实际也收不到货

因此：
- **π* 应该按产品单独设定**，反映该产品在当前市场的现实预期
- 对于预期微亏的产品：π* < 0，即 p_max 略高于收入，接受亏损换取供货稳定
- 对于强势产品：π* > 0，保持盈利收购

**π* 的来源：**
- 参考合约历史记录中的实际利润分布
- 结合市场数据中各产品的历史 PPLH（见 market_data.md）
- 初期手动设定，后期用历史数据校准

## 五、自动化计划

### 目标
在现有"收货参考价" widget 中新增**订单模式**，输入订单参数后自动生成分段广告收购价表。

### 输入参数（可自动抓取 or 手动填写）

| 参数 | 来源 | 备注 |
|------|------|------|
| P0（Q0 基础售价） | 从页面零售订单抓取 | 脚本已有抓取能力 |
| b（质量奖励%） | 从页面零售订单抓取 | 已有 bonusPct |
| qty（数量） | 从页面零售订单抓取 | 已有 qty |
| W（工资） | SimcoTools API | GET /v1/realms/0/resources/{id} |
| π*（目标利润） | 用户配置，**按产品存储** | localStorage，长期稳定 |

### 配置参数（手动设置一次，存 localStorage）

| 参数 | 说明 |
|------|------|
| 低Q段上限 A | 如 Q3 |
| 高Q段起点 B | 如 Q8 |
| 各段折扣系数 | 低/中/高三段，各自独立 |

### 输出

- 完整 Q0–Q12 的广告收购价表
- 标记甜区范围（颜色区分三段）
- 同时显示 p_max(Q)（参考）和 ad_price(Q)（实际广告价）

### 数据积累与校准（未来）

- 利用现有合约历史记录功能，统计各产品各Q段的**实际成交价 / p_max 比值**
- 积累足够数据后，自动建议各段折扣系数
- 同步更新各产品的现实 π* 估计

### 实现优先级

1. **P1**：核心计算（p_max + 折扣 → 价格表），订单参数手动输入
2. **P2**：从页面自动抓取 P0、b、qty（利用现有抓取框架）
3. **P3**：从 API 自动拉取工资 W
4. **P4**：合约历史数据统计 → 折扣系数校准建议

---

## 六、总结：一句话策略

> 以理论无差异步长（P0×b）算出各Q的利润上限，在甜区（中Q段）以 85–90% 折扣发布广告，高Q段步长略宽松，π* 按产品现实利润预期单独设定，不强求每笔交易盈利，而是追求长期加权正收益。
