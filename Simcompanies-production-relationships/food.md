## 产业概览

食品产业特点：
- 所有终端产品**均可在交易行交易**，有明确参考价格
- **品质对利润影响显著**：高品质产品售价溢价明显
- 品质规则：输入原料 Q(n) → 产出最高 Q(n+1)；Q0/Q1产品均使用Q0原料
- 多数基础农产品（苹果、蔬菜）品质溢价极小，加工品溢价更大

## 关键结论

### 1. 产量/hr 数据来源修正（重要）

Encyclopedia API `producedAnHour` 与游戏实际不符，**偏高约10-27%**。所有分析已改用 SimcoTools resources API：
```
GET https://api.simcotools.com/v1/realms/0/resources/{id}
→ resource.producedAnHour  ← 游戏实际值
→ resource.wages           ← 实际工资
```

| 产品 | Encyclopedia API（错误） | SimcoTools API（正确） | 偏差 |
|---|---|---|---|
| 沙拉 Salad | 2.366/hr | 1.853/hr | +27.7% |
| 汉堡包 Hamburger | 0.592/hr | 0.463/hr | +27.9% |
| 千层面 Lasagna | 1.775/hr | 1.390/hr | +27.7% |
| 咖喱角 Samosa | 2.071/hr | 1.621/hr | +27.8% |
| 面包 Bread | 13.037/hr | 11.028/hr | +18.2% |

### 2. 沙拉 Q4 是最优单步产品（综合利润+流动性）

PPLH **$604~**（Q5无市场数据），日均8,354件，量大价稳。
芝士成本占87%（Cheese Q2×2）——沙拉利润高度依赖芝士价格稳定性。
Q2/Q3 (PPLH $421~) 同样有数据可用，可作为保守起点。

### 3. 酱汁（Sauce id:138）是餐厅系的成本瓶颈

30天均价约 $1,393（Q0）。千层面Q5原料成本$1,814中酱汁占92%，肉丸亦如此。
若能**自产 Sauce**，这两个产品的 PPLH 会大幅提升。

### 4. 面包最优品质是Q4，不是Q5

面团Q3均价$143.93 < Q4均价$156.85，而面包Q5($242) ≈ Q4($242)。
导致 **Bread Q4 PPLH $521 > Q5 $381**。

### 5. 橙汁 Q0-Q4 基本无利润

Q0/Q1/Q2/Q3需近似价格，Q5才有$246~但仍为近似。
橙汁只有在**自种橙子**（接近零成本）的 VI 链中才有意义。

### 6. 苹果汁 Q5 意外高利润（$544~）

苹果Q0×8价格约$20.72，而Q5苹果汁均价$44.95，PPLH=$544~。
**注意**：Q4/Q5苹果价格均用Q0近似，实际需验证高品质苹果市价。
流动性极高（286,958件/天），若近似价格成立，是高性价比选项。

### 7. 冻披萨严格限Q3

Q4/Q5因高品质原料成本飙升而亏损（-$211~），务必控制在Q3。
Q3 PPLH $255，日均9,910件，流动性良好。

### 8. 鸡尾酒理论PPLH最高但需要协同

Q4 PPLH $702~，但日均仅793件，且需要橙汁×1+苹果汁×1+姜汁啤酒×2+咖啡粉×8，
即至少需要4条饮料生产线同时供应原料，单独建设意义不大。
